당곡고 데이터 과학 교재에서 가져온 부분

DS 1차시 원문　자연어 요청, 실행 결과 확인, 개선 요청　원 교재는 서울 기온 그래프를 만든다. 이 수업은 첫 앱의 제목과 안내만 세 줄로 띄운다.

DS 2차시 원문　공식 API 문서와 함께 요청하고 날짜·빈 응답을 지정　영화 API의 요청 구조를 급식 조회에 적용한다.

DS 5차시 원문　나이스 조회와 기간별 최다 등장 메뉴　교육청·학교 코드와 중식을 지정해 날짜별 메뉴를 읽고 제공 일수를 센다. 교사가 준비한 조회 함수를 함께 쓴다.

DS 15차시 원문　여덟 후보, 네 경기·두 경기·결승 한 경기　대결 한 번에 한 행을 쓰던 원 교재와 달리 이 앱은 최종 우승표만 집계한다. 교사 접수와 학생 선택 기록을 분리한다.

급식 API 자료를 함께 붙일 때

요청 주소　https://open.neis.go.kr/hub/mealServiceDietInfo

입력　ATPT_OFCDC_SC_CODE(교육청), SD_SCHUL_CODE(학교), MMEAL_SC_CODE=2(중식), MLSV_YMD(급식일). 기간 조회는 MLSV_FROM_YMD와 MLSV_TO_YMD.

응답　row의 MLSV_YMD와 DDISH_NM을 확인한다. 메뉴의 줄 구분은 <br/>이며, INFO-200은 조회 자료 없음이다. 인증 오류와 구분한다.
