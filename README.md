# 두근두근 급식실

[실습 웹앱](https://greatsong.github.io/dugeun-lunch-lab/) · [프롬프트 모음](https://greatsong.github.io/dugeun-lunch-lab/prompts.html) · [당곡 DS 1차시](https://greatsong.github.io/ds-danggok-2026/lesson01.html)

고등학생이 파이썬과 Streamlit으로 급식 앱을 만드는 8차시 실습실입니다. GitHub Pages에서 stlite로 파이썬을 실행합니다. 공통 예제는 로그인 없이 이용할 수 있습니다. 첫 앱의 소스와 배포 안내는 수업 첫 페이지에 있습니다.

교사용 접수대의 ‘여러 기기에서 함께 투표하기’에서 별도의 학급 방을 만들 수 있습니다. 학생에게는 참여 주소를, 교사는 관리 코드가 든 파일을 따로 보관합니다. 방의 사용 기간은 7일입니다. 하트는 누른 횟수로 집계합니다. 개인 월드컵은 섞어서 나눠 준 참가권 한 장에 우승표 한 장을 받습니다. 수업을 마감하고 다섯 명 이상 완주하면 메뉴별 결과가 열립니다.

공유 방은 Google Apps Script에 회차별 집계를 보관합니다. 참가자의 이름과 학번은 전송하지 않습니다. 교사가 학생 확인을 마치면 기기에서 회차별 중복 확인값을 계산합니다. 가상 학번으로 연습할 수 있습니다. 배식 설문에는 학생이 고른 양만 기록합니다.
